# Sign-up Form
[An intermediate HTML and CSS project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form) from the Odin Project. The main focus was in getting a good understanding of the `<form>` element and how to style and validate its various inputs.

I applied my own content. [Link to the website](https://stubberson.github.io/top-signup-form/).

> [!note] 
> Technologies used: HTML5, CSS3
